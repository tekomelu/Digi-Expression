MIDI Expression 0.5, digiemu c1b5735, OS 1.54 (MX01 build), 5 November 2026.

1. Which parameter words the render reads, and when (scripts/probe-reads.py,
   stock OS 1.54, notes on track 1):
   slots 1-16 (LFO1, LFO2)   read only inside the LFO stage 0x400ed766
   slots 17-36, 38-45        read only after it (from 0x40077eea)
   slot 37                   never read
   => 0.4 hooked only after the LFO stage, so LFO destinations did nothing.
      0.5 adds the LFO slots at the LFO stage's entry (lfo.s).

2. Velocity and the LFO-stage entry (track 1 set by memory: VEL DEST L1.DEP,
   V.DEP +32, V.SNS 50 %; notes on the auto channel):
   --- note v=20
   live_note(track 0, note 60, velocity 74, flag 0x10)        20 at 50 % -> 74
   L1.DEP word at the LFO stage: 16384 -> 18944               +20 x 32 x 4
   --- note v=127
   live_note(track 0, note 60, velocity 127, flag 0x10)
   L1.DEP word at the LFO stage: 18944 -> 32512               capped at the top
   --- change track (auto release)
   L1.DEP word at the LFO stage: back to 16384

3. Knob feel: the firmware's encoder accelerator (0x400c06ae) returns 0 in
   digiemu for the stock pages too (scripts/probe-acc.py: LFO page knobs,
   FLTR FREQ), so the knob feel can only be judged on the unit. The page
   calls it exactly as the stock pages and Digi Perform do.
