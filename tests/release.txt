# 0.2: leaving a track that auto-channel input touched gives the synth back
# the track's own values. MIDI track A selected, CHAN 1, rows ticked.
# The track change is simulated by writing the active-track variable
# (0x4197c6b4), which the mod polls; digiemu's panel ignores keys after MIDI.
mark live bend, pressure and wheel on the auto channel
midi ed 00 60
midi dd 50
midi bd 01 30
mark select audio track 1: expect PB centre, AT 0, MW 0 (the track's own)
poke 4197c6b4 0
wait 100
mark PB on the auto channel with the audio track selected: expect nothing
midi ed 00 70
mark select A again, then live PB via track A's own channel 9
poke 4197c6b4 8
wait 100
midi e8 00 50
mark select audio track 1: track-channel input is not released, expect nothing
poke 4197c6b4 0
wait 100
mark centre from channel 9
midi e8 00 40
wait 100
